# Güçlenme Planım — PWA

## GitHub Pages kurulumu
1. GitHub'da yeni bir depo oluştur.
2. Bu ZIP içindeki dosyaları deponun ana dizinine yükle.
3. Settings → Pages → Deploy from a branch → `main` ve `/ (root)` seç.
4. Kaydet. Birkaç dakika sonra verilen GitHub Pages adresini aç.
5. Android Chrome menüsünden **Ana ekrana ekle** seçeneğini kullan.

## Önemli
- Antrenman kayıtları `localStorage` ile yalnızca bu tarayıcı/cihazda tutulur. Tarayıcı verileri silinirse kayıtlar kaybolabilir.
- Uygulama 7 günlük döngü gösterir. Gün seçimi cihazda saklanır.
- Barfiks için güvenli ve sağlam bir bar gerekir. Bar yoksa asılma bölümünü atla; evde eşyalara tutunarak deneme yapma.
- Program özellikle her gün maksimum yüklenme yerine kuvvet, koşu ve toparlanmayı dönüşümlü düzenler. Yaşına uygun bir antrenör/beden eğitimi öğretmeniyle kontrol etmek iyi olur.
